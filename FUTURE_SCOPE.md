# Future Scope (Post‑MVP)

This MVP focuses on safe, templatized hero personalization. Below is a realistic, incremental roadmap for real‑world adoption.

---

## 1) Multi‑section personalization (next step)

**What:** Personalize more than just the hero (still finite + safe).

**Examples:**
- Product grid ordering (gaming vs office)
- Social proof cards (reviews tuned to intent)
- Feature highlights (performance vs value)
- Newsletter CTA copy

**Why:** Hero alone improves first impression, but conversion gains often come from secondary sections.

---

## 2) Smarter intent scoring

**What:** Expand scoring with more signals and weight tuning.

**Signals to add:**
- Time on site + scroll depth history
- CTA hover / click tracking
- Returning visitor vs new
- Device + screen size context

**Why:** Makes intent less brittle and improves accuracy for ambiguous queries.

---

## 3) Domain‑specific templates

**What:** Provide template packs per vertical (e‑commerce, SaaS, education).

**Why:** A gaming intent on a SaaS landing page is different from a gaming hardware store.

---

## 4) A/B testing + feedback loop

**What:** Variant experimentation and auto‑optimization.

**Approach:**
- Run 2 variants for same intent
- Track conversion events
- Promote winners based on performance

---

## 5) Admin UI / CMS integration

**What:** Allow non‑engineers to edit hero variants and assets.

**Why:** Real businesses won’t edit JS manually.

---

## 6) Real‑time API / Edge personalization

**What:** Host decision engine at the edge or via API with caching.

**Why:** Centralized updates, consistent logic across websites.

---

## 7) Compliance + privacy

**What:** Add consent gating, privacy modes, and minimal data retention.

---

## 8) Monitoring & observability

**What:** Dashboards for intent volume, variant performance, latency.

---

## MVP vs Future Scope Summary

**MVP (current):**
- Safe hero personalization
- Finite templates + assets
- Explainable decisions
- No backend required

**Future:**
- Multi‑section personalization
- Data‑driven optimization
- CMS + analytics pipeline
